🧭 About Orchestrator

Local A2A server that executes tasks using a team of Codex agents. The lead operates in read-only mode: analyzes the goal, breaks down work into bounded assignments, and delegates them to roles over the A2A protocol. Each role is an independent Codex invocation with its own model, reasoning effort, and sandbox. Writer roles work on the workspace one at a time, and the server tracks which files were actually modified. At the end, results undergo acceptance checks if specified. State is persisted in SQLite, allowing tasks to pause for human decisions or rate limits and resume after restart.
