## Smallest missing offline qualifications

1. Add a matched V41 harness that runs the same deterministic DAG and fake durations through legacy and concurrent engines, captures causal start/finish events and peak concurrency, then requires identical accepted candidate/check output. Existing unit tests do not compare the two paths.
2. Add one real server/engine V43 scenario: inject one bounded worker failure, have the controller investigate/repair, accept the final pinned candidate without an owner response, and assert authenticated status/steering remains usable during worker barriers.
3. Close the focused V39/V40 restart gaps with disposable DB/workspace fixtures for additive migration rollback and single-publication-authority enforcement across legacy/concurrent selection; current startup downgrade tests are useful but are not those gates.
4. Run the agreed affected/frozen suite after CN14 settles, recording baseline and exact inputs. Any full/acceptance command must include `--test-skip-pattern='candidate attributes and inherited Git configuration cannot execute filters while mirroring'`.

## Separate live boundary

V41 offline qualification can establish causal scheduling behavior, not real speedup, quality or cost. V43 Layer 6, real-provider throughput/Fast entitlement, and rollout/restart against an owned live target require separate explicit authorization and pinned task/model/settings protocol; no live result is present here.
