# AD-02/AD-03 source map

Evidence is from source and existing tests; no tests or live provider/quota calls were run.

## Legacy default server path

- Account selection: `src/account-profiles.js:11-13,37-48,111-129` persists active profile, autoSwitch, profile list, and maps active name to home. `src/server.js:1281-1291` composes the switching App Server unless one is injected; injection disables automatic account switching. `src/app-server-switch.js:126-135` changes active profile and refuses a physical swap while calls are in flight. `src/budget-watcher.js:135-165` checks other configured homes in profile order, then system home, selects first available, sets active and switches.
- Provider identity/thread context: `src/app-server-switch.js:105-120` records call-bound identity and returns codexHome on relevant responses; `src/server.js:1283-1285` connects this to the dispatch journal. Legacy task pause/resume is still routed through same orchestrator/task id (`src/server.js:1703-1705`); watcher does not explicitly prepare a new provider thread or transfer a checkpoint. AD-02's safe context transfer is therefore not evidenced as an implemented legacy behavior.
- Quota signal: `src/server.js:1537-1549` supplies active App Server `readRateLimits` and per-home reader. `src/server.js:1693-1700` creates a short-lived App Server against each home. `src/budget-watcher.js:28-49` treats only `ordinaryUsageAllowed` or explicit non-reached rate-limit snapshots as availability; `52-63` uses reset timestamps only as scheduling hints.
- Durable wait/restart: legacy wait is task pause metadata, discovered by `listBudgetPausedRuns` and watcher startup at `src/server.js:1540-1541,1564`; watcher registers discovered pauses in `src/budget-watcher.js:266-289`. Automatic switch/resume logic is in `src/budget-watcher.js:175-213`.
- Existing tests: `test/account-profiles.test.js`, `test/app-server-switch.test.js`, `test/budget-watcher.test.js`, `test/server-delivery-engine.test.js`. Watcher tests explicitly cover availability, recheck, startup registration, switching, profile-change wake, and reset hint behavior (`test/budget-watcher.test.js:123-140,227-235,271-280,403-427`). They do not establish two-account same-objective checkpoint transfer or provider-thread safety end-to-end.

## Concurrent engine path

- Identity pin: `src/concurrent-delivery-engine.js:100-114,129-141` requires and stores a provider identity and identity getter per engine. `946-951` detects account/home drift. `953-970` resume eligibility currently only accepts `paused_owner` or `blocked_technical`; `#resumeWithCurrentProvider` is reached from resume on provider drift (`876-900,1025+`), so `waiting_budget` is excluded. Startup recovery similarly leaves changed-identity work dormant (`476-495`). A restart test asserts dormant identity drift (`test/concurrent-delivery-engine.test.js:1328-1336`).
- Durable wait: `src/backlog-store.js:886-925` persists wait metadata, moves objective to `waiting_budget`, and stores lifecycle control; `932-959` wakes only when due and control pins match. `src/delivery-lifecycle.js:35-63,98-135,196-207` supplies eligibility callback, checks it synchronously, and triggers wake callback. Default eligibility is false (`delivery-lifecycle.js:37`).
- Composition gap: lifecycle is created within concurrent controller (`src/concurrent-delivery-engine.js:402-406,846+`); current composition shown at shutdown has no budget eligibility/wake callback. `src/server.js:1534-1554` budget watcher lists/resumes mapped paused runs through router but only legacy account-switching adapter exists. Router maps each run immutably to engine (`src/delivery-engine-router.js:105-129,149-169`), making it the natural dispatcher boundary; it does not itself provide concurrent budget wake wiring.
- Existing tests: `test/delivery-lifecycle.test.js:35-67,230-253` checks trusted eligibility and persisted lifecycle restart for retries; concurrent tests cover a budget wait boundary retaining `waiting_budget` (`test/concurrent-delivery-engine.test.js:1505-1527`) but not automated budget eligibility, restart wake, or provider rebind from that state. `test/delivery-engine-router.test.js` covers routing contract.
