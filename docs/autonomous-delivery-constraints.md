## Scope boundary

The source review checked the server composition, engine router, lifecycle caller,
account switching wrapper and runner caller before classifying absences. No live
provider run or account switch was performed. Root's local 90-percent dispatch
policy is independent from runtime product behavior. The historical handoff's
no-default-round-cap statement conflicts with the current constructor default and
server composition; tracked entry points should be corrected during backlog
integration. The local runner and lead-policy files are evidence of development
controls only; their paths are not portable product dependencies.
