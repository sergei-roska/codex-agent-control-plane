# Project instructions for Claude Code

Read and follow [AGENTS.md](AGENTS.md) before working in this project.

The dashboard reference at `artifacts/dashboard/**` is immutable. Use the
independent working copy at `web/dashboard/**` for implementation and builds.

The roadmap is [docs/beta-master-plan.md](docs/beta-master-plan.md).

Session continuity: while a milestone is open, start every session by reading
its handoff, currently [docs/m9/session-handoff.md](docs/m9/session-handoff.md),
and verify the state it names before acting. Update the handoff and commit
verified work at each checkpoint.
