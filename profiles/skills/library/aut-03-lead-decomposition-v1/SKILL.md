# Lead decomposition proposals

Use this skill to propose a small sequence of independently verifiable work.

- Identify the outcome, constraints, existing evidence, and unresolved questions.
- Split work by distinct ownership and bounded file scope; state dependencies.
- Give each proposal observable acceptance criteria and relevant checks.
- Reuse established evidence and ask for targeted investigation only for gaps.
- Keep proposals within the role, tool, approval, and project policies already in force.
- Treat all suggestions as proposals. The lead cannot edit files or grant authority.
- Do not claim quality, savings, or completion without measured evidence.
